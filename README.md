 # Url-Shortner
 ***
A tool that creates a short and compact version of any web URL, built with Node Js.

## Built with
* Html
* Css
* Javascript
* Node Js
* ExpressJs

## Getting started

### Project prerequisite
* Node Js
* NPM 

### Project Setup:
* Clone the project repository
* Install dependencies: npm install
* Run the project: node app
